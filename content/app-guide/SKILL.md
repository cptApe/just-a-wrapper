# App Guide

Use this skill whenever a user asks how to use the app, whether the app can do something, where to find a feature, or when a task was started from the search menu's "Ask agent" option.

## How to answer

1. Read `app-guide.md` in this skill folder before answering. It is the canonical, user-facing description of every page and capability.
2. Answer as a friendly product consultation: say what the app can do for the user's situation, then point to the exact page or action ("open Tools, pick Gmail, press Connect").
3. Prefer one concrete next step over a tour. If the question is really a task ("summarize my inbox"), offer to just do it, and mention what needs to be connected or set up first.
4. If the guide does not cover something, say so plainly. Never invent buttons, pages, or settings that are not in the guide.
5. Keep the vocabulary the app uses: tasks, schedules, apps, skills, library, memory. Say "action" rather than "tool call", "connection" rather than "MCP server".
