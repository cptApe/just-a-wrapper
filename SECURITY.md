# Security

Report vulnerabilities through this repository's **Security → Advisories → Report a vulnerability** page on GitHub. Use a private advisory, not a public issue or pull request. If private reporting is unavailable, ask the maintainers to enable it without posting vulnerability details publicly.

Include affected versions, reproduction steps, expected impact and a minimal example with secrets and personal data removed. Do not include live credentials or another user's records.

## Supported versions

Security fixes go to the latest release on `main`. Forks pull them from upstream; check [CHANGELOG.md](CHANGELOG.md) for releases that include them.
